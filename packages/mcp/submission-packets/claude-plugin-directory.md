## What the plugin bundles

- **One remote MCP connector** — `{"type": "http", "url": "https://mcp.leadbay.app/mcp"}`.
  No `userConfig`, no pasted token: the host runs OAuth. Claude Code uses an
  RFC 8252 loopback redirect, so Stargate must accept `http://localhost/callback`
  and `http://127.0.0.1/callback` port-agnostically.
- **14 skills** under `skills/`, generated by `@leadbay/promptforge` from the
  same `.md.tmpl` sources as the MCP prompts — CI fails on drift. They cover the
  end-to-end jobs: `leadbay_getting_started`, `leadbay_daily_check_in`,
  `leadbay_followup_check_in`, `leadbay_research_a_domain`,
  `leadbay_qualify_top_n`, `leadbay_refine_audience`, `leadbay_log_outreach`,
  `leadbay_import_file`, `leadbay_plan_tour_in_city`,
  `leadbay_prospecting_overview`, `leadbay_extend_my_lens`,
  `leadbay_setup_team_prospecting`, `leadbay_build_campaign`,
  `leadbay_work_campaign`, `leadbay_top_accounts_to_activate`.
- **`SETUP.md`** — the setup skill Claude follows to walk a user through
  connecting on first install.

That is the shape Anthropic asks for: a connector plus the skills that teach
Claude the sales process, not a bare tool list.

## Version discipline

`plugin.json.version` tracks `packages/mcp/package.json`, asserted by
`packages/mcp/test/audit/plugin-manifest-version.test.ts`. It drifted to 0.29.0
for seven releases before that audit existed.

After publication, pushes to `main` are mirrored automatically; the form is not
re-submitted for updates.
