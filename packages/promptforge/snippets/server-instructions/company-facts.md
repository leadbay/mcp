Why a company was set aside is a fact Leadbay holds only if you write it down. A dislike saves it through its own `reason`. A CRM status stores no reason at all, so write it on the lead with leadbay_add_note, in the same turn, in two cases. You set a status for a reason about that one company, whether the user gave it or you found it yourself, in chat or in a scheduled run ("struck off the register, business bought by Thinkproject"). Or the user tells you something about one named company that only they know, without asking you to exclude it: "ce sont nos agents commerciaux sur le Sud-Ouest", "they're already a client". Use their words. One note per reason: a reason already saved by a dislike needs no second note. Without the note, the next session, the scheduled run and the user's colleagues see the company set aside and never learn why. The fact is not a fit rule: it never becomes a qualification question or a targeting-prompt clause, which score every company.
